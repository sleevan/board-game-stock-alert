GitHub access

Saving changes needs a GitHub token limited to this one repository. It's stored only in this browser.

  1. Open GitHub → New fine-grained token.
  2. Token name: Game Stock Watch. Expiration: your choice (up to a year, or none).
  3. Repository access: Only select repositories → board-game-stock-alert.
  4. Permissions → Repository: Contents: Read and write and Actions: Read and write (Actions powers "Check now").
  5. Generate, copy the token, and paste it here.

Runs every 30 minutes on GitHub from the repository. Store list from Board Game Oracle.
